[App Store](https://apps.apple.com/app/id6818752464) · [Google Play](https://play.google.com/store/apps/details?id=com.andreykotlyar.guitar0)

## Features

- Courses and lessons with video, songs with chords and strumming patterns
- Chord library and favorites
- Tuner and metronome
- Fully offline: lesson content ships with the app and syncs in the background
- Lesson progress and practice activity
- Donations via in-app purchases

## Prerequisites

- Node.js 26 (same as CI)
- Xcode (iOS) and/or Android Studio (Android)

The app uses native modules, so it runs in a [development build](https://docs.expo.dev/develop/development-builds/introduction/), not in Expo Go. `ios/` and `android/` are generated by `npx expo prebuild` and are not committed.

## Quick Start

```bash
cp .env.example .env.local
make install
make ios        # or: make android
```

The first run builds the native app; afterwards `make start` is enough for JS changes. The app talks to the production API by default (`EXPO_PUBLIC_API_URL`). Analytics stays off in development builds.

## Development Commands

```
make help           list all available commands

make lint           ESLint
make format-check   Prettier check
make typecheck      TypeScript type check
make test           Jest
make ci             lint + format-check + typecheck + test

make start          start Expo dev server
make ios            build and run on iOS
make android        build and run on Android
```

Other scripts in `package.json`:

```
npm run test:coverage      Jest with coverage report
npm run generate:types     regenerate src/lib/network/api.types.ts from the API schema
npm run db:generate        generate a Drizzle migration after a schema change
npm run content:snapshot   refresh the bundled lesson content and scheme images
npm run deps:check         check Expo package versions
```

## Offline Content

Courses, lessons, songs, chords and schemes live in local SQLite and work without a network connection, including the first launch. `assets/content/lessons.snapshot` is the `/api/v1/sync/lessons/` response bundled with the app; at startup it is applied when it is newer than the local data. In the background the app fetches a delta from the server. Network errors never block the UI.

## Project Structure

```
src/app/              Expo Router routes; screens stay thin
src/features/         domain modules (lessons, songs, chords, tuner, metronome, donations, …)
src/lib/              infrastructure: db, network, sync, themes, analytics
src/lib/dev/          __DEV__-only tools, stripped from release builds
src/components/ui/    generic UI primitives
drizzle/              SQLite migrations
assets/content/       bundled lesson content snapshot
scripts/              content snapshot and Lottie build scripts
```
